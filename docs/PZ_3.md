## Бланк 4. Ключевой Use Case №1: «Забронировать тур»

**Роли:** пользователь/аналитик — Денис (турист), Руслан (аналитик)  
**Основной актор:** Турист  
**Вспомогательные акторы:** Платежный сервис, Гид  
**Заинтересованные стороны:** Турист (место на туре), Гид (заполнить слот), Платежный сервис (провести транзакцию).  
**Предусловие:** Тур опубликован, есть свободные слоты, турист авторизован.  
**Триггер:** Турист хочет записаться на тур.

| № шага | Кто действует | Что происходит (намерение)                            |
| :----- | :------------ | :---------------------------------------------------- |
| 1      | Турист        | Выбирает тур из каталога                              |
| 2      | Система       | Показывает карточку тура с описанием, ценой и слотами |
| 3      | Турист        | Выбирает дату и время из доступных                    |
| 4      | Система       | Проверяет, что слот свободен, и резервирует место     |
| 5      | Турист        | Указывает контактные данные                           |
| 6      | Система       | Создает бронь со статусом «ожидать оплаты»            |
| 7      | Турист        | Оплачивает бронь (тестовый режим)                     |
| 8      | Система       | Подтверждает оплату и меняет статус на «оплачено»     |
| 9      | Система       | Отправляет уведомление туристу и гиду                 |

**Постусловие (успех):** Бронь создана и оплачена, слот закрыт, турист и гид уведомлены.  
**Гарантированный результат (при неуспехе):** Если оплата не прошла — бронь не создается, слот остается свободным.

## Бланк 5. Ключевой Use Case №2: «Создать тур»

**Роли:** пользователь/аналитик — Степан (гид), Денис (аналитик)  
**Основной актор:** Гид  
**Вспомогательные акторы:** Модератор (получает тур на проверку).  
**Предусловие:** Гид зарегистрирован и авторизован.  
**Триггер:** Гид хочет добавить новый тур.

| № шага | Кто действует | Что происходит                             |
| :----- | :------------ | :----------------------------------------- |
| 1      | Гид           | Начинает создание нового тура              |
| 2      | Система       | Запрашивает название, описание, фото       |
| 3      | Гид           | Заполняет основные данные                  |
| 4      | Система       | Проверяет заполненность обязательных полей |
| 5      | Гид           | Добавляет точки Story Trail (текст, медиа) |
| 6      | Система       | Сохраняет черновик                         |
| 7      | Гид           | Настраивает расписание (слоты)             |
| 8      | Система       | Сохраняет расписание                       |
| 9      | Гид           | Отправляет тур на модерацию                |

**Постусловие (успех):** Тур создан и отправлен на модерацию, черновик сохранён.  
**Гарантированный результат (при неуспехе):** Если обязательные поля не заполнены — тур не сохраняется.
