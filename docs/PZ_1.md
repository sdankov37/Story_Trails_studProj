## Бланк Б. Карточка сквозного продукта

| Поле                                                              | Запись команды                                                                                                                                                                                                                                                                                                                                                                                                   |
| :---------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Краткое описание продукта в одном предложении**                 | «Местные истории» — это веб-платформа туров, где локальные гиды создают иммерсивные Story Trails и мини-игру «Собери маршрут», а туристы проходят их, бронируют и оплачивают впечатления онлайн.                                                                                                                                                                                                                 |
| **Пользователь или представитель партнёра**                       | Пользователи: локальные гиды и туристы.                                                                                                                                                                                                                                                                                                                                                                          |
| **Главная работа пользователя, которую продукт должен упростить** | Организация и бронирование туров: для гида — превращение своей экспертизы в продаваемые впечатления и управление ими без рутины, для туриста — поиск, выбор и оплата уникального локального опыта.                                                                                                                                                                                                               |
| **Результат к концу семестра**                                    | Работающий MVP с полным сквозным сценарием «гид → турист → бронь → оплата → отзыв», мини-игрой и Story Trails, а также документацию, тесты, CI/CD и деплой. Всё это можно проверить вживую и подтвердить метриками.                                                                                                                                                                                              |
| **Нижняя граница качества**                                       | 1) То, что показано на защите, работает на подготовленных данных без ручного вмешательства команды.<br>2) Пользователь с ролью «турист» не может войти в кабинет гида и наоборот — проверено тестом.<br>3) Проект запускается одной командой, README описывает запуск, тесты проходят.<br>4) Оплата в тестовом режиме (без реальных денег).                                                                      |
| **Переменная величина при отставании**                            | Объём функций сокращается, качество оставшихся не опускается ниже границы. Порядок сокращения:<br>1) Сложная аналитика, интеграции (погода, внешние карты), мультиязычность.<br>2) Мини-игра «Собери маршрут» упрощается до линейного маршрута без ветвлений.<br>3) Story Trail сокращается до текстовых точек без аудио.<br><br>**Не сокращаем никогда:** бронирование, разграничение ролей, сквозной сценарий. |
| **Что точно не входит в MVP сейчас**                              | 1) Реальная аттестация гидов<br>2) Автоматические выплаты гидам<br>3) Мобильное приложение<br>4) AI-функции<br>5) Социальные функции<br>6) Real-time чат<br>7) Сложная аналитика<br>8) Внешние интеграции (погода)<br>9) Монетизация платформы                                                                                                                                                                   |
