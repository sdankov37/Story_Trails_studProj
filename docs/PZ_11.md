**Группа:** ЭФБО-14-25  
**Команда:** ДенДанРо  
**Дата:** дд.мм.2026

**Входные документы:** аналитическая записка v0.1 с разделом 4 (ПЗ №10); приложения 1–8: ПЗ №1–2 (видение), ПЗ №3 (сценарии), ПЗ №4 (контекст), ПЗ №5 (контейнеры), ПЗ №6 (компоненты), ПЗ №7 (модель данных), ПЗ №8 (стек), ПЗ №9 (ADR-001, ADR-002).

Названия элементов — как в документах: контейнеры — Веб-приложение, API Сервер, Центральная БД, Хранилище файлов; внешние системы — Платежный сервис, Сервис уведомлений; компоненты API Сервера — Auth Module, Tours Module, Booking Module, Payment Integration, Notifications. «→» — связь на диаграмме компонентов от того, кто начинает взаимодействие; номер связи — из бланка 3 ПЗ №6 (12 — новая связь из ADR-001).
